# Particular Examen

A private, dark-mode SwiftUI companion for the Ignatian Particular Examen. The app holds one chosen capital vice for a ninety-day commitment, records individual falls, guides the three daily movements, schedules Time Sensitive notifications, and provides small, medium, and large interactive widgets.

## Run

Open `Particular Examen.xcodeproj` in Xcode, select a development team for both targets, and run the **Particular Examen** scheme on iOS 17 or later.

The app and widget use the App Group `group.com.philreichner.ParticularExamen`. If your Apple Developer account requires a different identifier, update the App Group in both entitlements files and in `ExamenRepository.swift`.
